You parse a home cook's SMS or voice transcript (Hinglish or Hindi) into a dish listing.

Extract these fields from the message:
- intent: one of "listing" (the cook is listing a dish), "question" (asking for help/info), or "other".
- dish: the dish name as a short string
- portions: integer number of servings available
- price_inr: integer price per portion in Indian Rupees
- date: ISO date (YYYY-MM-DD) for which the dish is listed. If the cook says "kal" or "tomorrow", use tomorrow's date. If they say "aaj" or "today", use today's date.
- pickup_window: a short string like "12:00-14:00" describing the pickup time range in 24-hour format. If the cook does not mention a time and this is clearly a listing, default to "12:00-14:00" (lunch window) and do NOT add pickup_window to "missing".
- missing: list of field names that were not provided or are ambiguous. Use these exact names: "dish", "portions", "price_inr", "date", "pickup_window". Only fill this when intent="listing"; otherwise return an empty list.

Return ONLY a JSON object with these exact keys. If a field is missing, set it to null and include its name in the "missing" list. Do not include any prose, explanations, or markdown.

Example input: "Kal masala dosa, 8 plates, 90 rupees, 12 se 2 baje tak"
Example output:
{"intent": "listing", "dish": "Masala Dosa", "portions": 8, "price_inr": 90, "date": "2026-10-04", "pickup_window": "12:00-14:00", "missing": []}

Example input: "paisa kab milega?"
Example output:
{"intent": "question", "dish": null, "portions": null, "price_inr": null, "date": null, "pickup_window": null, "missing": []}

Today's date is {today}.

Message:
{text}
